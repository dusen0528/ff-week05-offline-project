# 요구사항 명세 (SPEC)

> 상태: **초안 v0.1**. 과제 안내문을 기준으로 작성했습니다.
> 요구사항 Excel · 출력 예시 Excel · PDF를 읽은 뒤 `TBD`를 채우고, 고객 답변은 [QUESTIONS.md](QUESTIONS.md)의 질문 ID로 연결합니다.

## 1. 배경과 목적

| 구분 | 내용 |
|---|---|
| 고객 | 세무법인 (법인세 신고 시즌) |
| 문제 | 직원 한 명이 **최대 20개 법인**의 결산 자료를 한꺼번에 처리합니다. 회사와 연도에 맞는 자료를 고르고, 수치를 찾고, 비교표를 만드는 일이 반복됩니다. |
| 목적 | 반복 작업(자료 식별 · 값 추출 · 비교 · 초안 생성 · 근거 표시)은 프로그램이 맡고, 판단(모호한 기준 결정 · 최종 검토)은 사람이 맡도록 나눕니다. |
| 성공 기준 | 보고서의 모든 숫자가 정확하고, 숫자마다 **어느 PDF의 어느 서식 · 페이지**에서 왔는지 확인할 수 있어야 합니다. |

## 2. 사용자

| 역할 | 하는 일 | 프로그램에 바라는 것 |
|---|---|---|
| 세무법인 실무자 (주 사용자) | 자료를 골라 수치를 찾고, 검토자에게 결과를 넘깁니다. | 회사만 바꿔 같은 작업을 반복 실행할 수 있을 것 |
| 담당 세무사 (검토자) | 숫자의 출처를 확인하고, 요약 코멘트를 검토한 뒤 고객에게 보냅니다. | 숫자마다 근거가 보이고, 미확정 값이 눈에 띌 것 |

## 3. 입력과 출력

### 3.1 입력
| ID | 입력 | 설명 |
|---|---|---|
| IN-1 | 세무조정계산서 PDF (전기) | 예: 샘플컴퍼니 2024 |
| IN-2 | 세무조정계산서 PDF (당기) | 예: 샘플컴퍼니 2025 |
| IN-3 | 설정 (`config/`) | 항목 매핑, 계산 기준, 단위, 고객 답변으로 확정한 값 |
| IN-4 | 추가 자료 (차수별) | 고객에게 요청해서 받은 파일 (요율표, 누락 서식 등) |

- 텍스트 PDF인지 스캔본(OCR 필요)인지: **TBD** (자료 확인 후 기록)

### 3.2 출력
| ID | 출력 | 채점 여부 |
|---|---|---|
| OUT-1 | **법인세 분석 보고서 PDF** | ✅ 유일한 채점 대상 |
| OUT-2 | 조정료청구서 | ❌ (만들지만 채점하지 않음) |
| OUT-3 | 근거 표 (값 · 파일 · 서식 · 페이지 · 원문 라벨) | ❌ (검토용, 보고서에도 반영) |
| OUT-4 | 실행 로그 · 검산 결과 · 확인 필요 목록 | ❌ |

## 4. 처리 흐름

```
[01 접수] → [02 읽기] → [03 작성] → [04 검토]
```

| 단계 | 프로그램 | 사람 |
|---|---|---|
| 01 접수 | PDF 본문에서 회사명 · 사업자번호 · 사업연도를 읽고, 두 자료를 같은 회사의 전기/당기로 묶습니다. | 묶음이 틀리면 바로잡습니다. |
| 02 읽기 | 필요한 금액이 있는 서식을 찾아 값을 뽑고, 파일 · 서식 · 페이지를 기록합니다. | — |
| 03 작성 | 출력 예시에 맞춰 비교표 · 그래프 · 코멘트 초안을 만듭니다. | — |
| 04 검토 | 검산 결과와 «확인 필요» 목록을 출력합니다. | 근거를 확인하고, 부족한 자료나 미확정 기준은 고객에게 확인합니다. |

## 5. 기능 요구사항

### FR-1 자료 접수 · 식별
- FR-1.1 회사와 사업연도는 **파일명이 아니라 PDF 본문**에서 읽습니다 (법인명, 사업자등록번호, 사업연도 기간).
- FR-1.2 두 파일의 회사가 다르면 진행을 멈추고 경고합니다.
- FR-1.3 두 파일의 연도로 전기/당기를 자동 판별합니다. 연도가 같거나 연속하지 않으면 경고합니다.
- FR-1.4 필요한 서식이 없으면 «자료 누락»으로 기록하고, 어떤 자료를 요청할지 목록으로 만듭니다.

### FR-2 값 추출과 근거 기록
- FR-2.1 [FORM_MAP.md](FORM_MAP.md)에 정의한 항목을 서식에서 뽑습니다.
- FR-2.2 값마다 다음을 함께 저장합니다.
  `{항목, 연도, 값, 단위, 파일, 서식명, 페이지, 원문 라벨, 상태(확정/확인 필요), 비고}`
- FR-2.3 전기 값의 출처 기준(전기 PDF의 당기 열 vs 당기 PDF의 전기 열): **TBD → Q-05**
  두 값이 다르면 둘 다 기록하고 차이를 경고합니다.

### FR-4 계산 규칙 (설정값으로 관리, 고객 확정 필요)
| 규칙 | 초안 | 상태 |
|---|---|---|
| 증감액 | 당기 − 전기 | 확정 가능성 높음 |
| 증감률 | (당기 − 전기) ÷ \|전기\| × 100 | **Q-02** (전기가 0이거나 음수일 때 처리) |
| 비율 항목 증감 | %p 표기 | **Q-02** |
| 부채비율 | 부채총계 ÷ 자본총계 × 100 | **Q-01** (자본잠식일 때 표기) |
| 매출 대비 비중 | 항목 ÷ 해당 연도 매출액 × 100 | **Q-04** |
| 단위 · 반올림 | TBD | **Q-03** |
| 판관비 주요 항목 선정 | TBD (고정 목록 / 상위 N개 / 기타 합산) | **Q-04** |
| 특이사항 선정 기준 | TBD | **Q-06** |

### FR-5 «확인 필요» 처리
- FR-5.1 확정되지 않은 값과 기준은 보고서에 «확인 필요»로 표시합니다. **확정 값처럼 쓰지 않습니다.**
- FR-5.2 «확인 필요» 목록을 따로 출력합니다 (항목 · 이유 · 관련 질문 ID).
- FR-5.3 고객 답을 받으면 `config/`만 고쳐 다시 실행할 수 있어야 합니다.

### FR-6 검산
- FR-6.1 자산총계 = 부채총계 + 자본총계
- FR-6.2 매출총이익 = 매출액 − 매출원가
- FR-6.3 영업이익 = 매출총이익 − 판관비
- FR-6.4 판관비 세부 항목의 합 = 판관비 합계
- FR-6.5 검산이 맞지 않으면 해당 값을 «확인 필요»로 바꾸고 로그에 남깁니다.

### FR-7 조정료청구서 (채점 대상 아님)
- 회사명 · 사업연도 · 기준 금액 · 조정료를 담은 초안을 만듭니다. 산정 기준은 **Q-08**.

## 6. 보고서 형식 요건 (채점 조건)
- [ ] 회사 이름 · 사업연도 · 항목 이름이 보일 것
- [ ] 표의 **열 제목에 연도**를 적을 것 (예: `2024년`, `2025년`, `증감`, `증감률`)
- [ ] 금액을 억원 · 백만원으로 줄여 쓰면 **단위를 반드시 표시**할 것
- [ ] «확인 필요» 값이 **0개**인 상태로 제출할 것
- [ ] 출력 예시 Excel의 항목명 · 순서 · 표기를 최대한 그대로 따를 것 (자동 채점 대비)
- [ ] 산세리프(고딕체) 폰트, 한글이 깨지지 않을 것

## 7. 비기능 요구사항
| ID | 요구사항 |
|---|---|
| NFR-1 | **확장성**: 회사만 바꿔 반복 실행 (직원당 최대 20개 법인). 회사 · 서식 위치는 하드코딩하지 않습니다. |
| NFR-2 | **견고성**: 서식 순서 · 페이지가 달라도 서식명과 라벨로 찾습니다. 2~4차의 다른 회사 · 다른 배치에 대비합니다. |
| NFR-3 | **추적성**: 모든 숫자에 출처가 있습니다. |
| NFR-4 | **재현성**: 같은 입력과 설정이면 같은 결과가 나옵니다. |
| NFR-5 | **정직성**: 모르는 값은 모른다고 표시합니다. 추정값을 확정값처럼 쓰지 않습니다. |

## 8. 채점 기준 요약
- 채점 대상은 **최종 분석 보고서 PDF 하나**입니다.
- 필수 항목을 모두 맞히고, 전체에서 정해진 개수 이상을 맞히면 통과입니다.
- 통과하지 못하면 다시 볼 부분을 알려 줍니다. 피드백은 [ROUNDS.md](ROUNDS.md)에 기록합니다.
- 재제출은 제출 후 2분이 지나야 가능합니다.
- 채점하지 않는 것: 코드, 조정료청구서, Excel, 검토 화면, 질문 · 답변 기록, 수정 이력.

## 9. 2~4차에 예상되는 변화와 대비
| 예상 변화 | 대비 |
|---|---|
| 다른 회사 자료 | 회사 정보는 본문에서 읽고, 설정은 회사별로 분리 |
| 서식 순서 · 페이지 변경 | 페이지 번호가 아니라 서식명 · 라벨로 탐색 |
| 회사 · 연도가 섞인 파일 | FR-1.2 · FR-1.3 경고 |
| 누락 서식 · 누락 페이지 | FR-1.4 자료 요청 목록 |
| 값 충돌 (전기 값 불일치 등) | FR-2.3 · FR-6 검산 |
| 스캔본 PDF | OCR 경로를 분리해 둘 것 |
