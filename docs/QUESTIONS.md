# 고객 질문 로그 (QUESTIONS)

> 규칙
> - 처음 적은 질문은 **지우지 않습니다**. 고칠 때는 `v2`로 덧붙입니다.
> - 질문은 업무 용어로 쓰고, **한 번에 모아서** 보냅니다. 고객은 답이 늦습니다.
> - 답변 분류는 셋입니다.
>   - `답변 있음`
>   - `불명확·충돌`
>   - `답변 없음`: «확인해보고 말씀드릴게요»도 여기에 넣습니다.
> - 답을 받으면 [DECISIONS.md](DECISIONS.md)의 해당 결정 상태를 `확정(고객)`으로 바꾸고, `config/answers.yaml`에 반영합니다.

## 2.1 질문 운영 교훈 (2026-11-21)
- 고객 화면은 채점과 관계없는 질문에 **「해당 문제에 필요 없는 질문입니다」**를 붙입니다. Q-02와 Q-03의 표기 세부(소수점, 병기, 신규)가 여기에 걸렸습니다.
- 앞으로는 **채점되는 숫자나 섹션을 바꾸는 질문만** 보냅니다. 표기 취향, 채점 대상이 아닌 산출물(조정료청구서, Excel, 폰트, 발행 정보), 우리가 정해도 되는 구현 세부는 묻지 않고 DECISIONS에 `설계`로 정합니다 (D-023).
- 고객이 «정해진 것 없음»이라고 답한 표기는 고객 예시에서 추론하거나 설계로 정합니다. «확인 필요»로 남기지 않습니다.
