## D-001 두 Excel 파일의 역할
- **상태**: 확정(자료) · 2026-11-21
- **내용**
  - `요구사항.xlsx`: 고객이 쓴 요구사항입니다.
    - 시트 이름이 「(작성중)」입니다.
    - 조정료청구서 3~5번 칸이 비어 있습니다.
    - 전체 틀 #3 문장이 "(예시 :"에서 끊겨 있습니다.
  - `보고서_출력예시.xlsx`: 「법인세 신고 결과 보고서」입니다.
    - 2021·2020 사업연도, 매출 41,543,593원으로, **샘플컴퍼니가 아닌 다른 회사**의 예시입니다.
    - 구성은 Ⅰ.법인 기본사항 / Ⅱ.표준재무제표·재무비율 / Ⅲ.연도별 신고상황 / Ⅳ.신고 참고자료 / Ⅴ.신고 결과 보고입니다.
- **영향**
  - 예시 Excel의 숫자를 정답으로 쓰지 않습니다.
  - 형식, 표기, 비율 공식만 참고합니다.
  - 구성 차이는 Q-01, 빠진 내용은 Q-09로 묻습니다.

## D-003 금액의 1순위 출처
- **상태**: 잠정 (Q-04로 계정명 기준 확인)
- **결정**
  - 보고서 금액은 **결산보고서의 재무상태표·손익계산서**에서 가져옵니다 (2024 p35·36, 2025 p54·55).
  - 표준재무상태표와 표준손익계산서는 **검산용**입니다.
- **이유**
  1. 판관비 계정명이 다릅니다. 표준손익계산서는 외주용역비를 「37.기타」, 도서인쇄비를 「30.인쇄비」로 묶습니다. 고객이 읽는 보고서에는 결산서 계정명이 자연스럽습니다.
  2. 요구사항 #7이 「결산 부속명세서」를 직접 언급합니다.
  3. 두 출처의 합계는 일치합니다. 매출, 판관비, 영업손익, 당기순손익 모두 같습니다.
- **대안**: 표준손익계산서 코드(68·79·80…) 기준. 회사가 바뀌어도 코드가 같다는 장점이 있습니다. 그래서 **검산·매핑 키로는 계속 씁니다**.

## D-005 부채비율
- **상태**
  - 공식: 확정(요구사항 #1 + 예시 Excel 「비율산정공식: 부채/자기자본 * 100」)
  - 표기: 잠정 (Q-02)
- **결정**: 부채비율 = 부채총계 ÷ 자본총계 × 100. 자본총계가 0 이하이면 «자본잠식»으로 표시합니다.
- **값**
  - 2024: 19,555,334 ÷ (-5,510,353) → -354.88% → **자본잠식**
  - 2025: 21,224,676 ÷ 40,985,771 = **51.79%**
- **열린 점 (Q-02)**: «자본잠식»만 쓸지, 숫자를 같이 쓸지(-354.88%). 증감 칸을 어떻게 쓸지(예: «자본잠식 해소»).

## D-006 단위와 표기
- **상태**
  - 단위: 확정(요구사항 #1·#4·#5)
  - 소수점·반올림: 잠정 (Q-02)
- **결정**

  | 섹션 | 단위 | 근거 |
  |---|---|---|
  | R-1 주요 지표 비교 | **억원** | 요구사항 #1 |
  | R-4 요약 손익 비교 | **원** | 요구사항 #4 |
  | R-5 판관비 주요 항목 | **원 (전체 금액)** | 요구사항 #5 |
  | 비율 | % 소수 둘째 자리 | 예시 Excel 재무비율 (49.57 등) |

- **열린 점**
  - 이 회사는 억원으로 쓰면 숫자가 작습니다. 매출 0.93 → 1.93억원, 영업이익 -0.15 → 0.49억원입니다.
  - 그래서 억원 소수 몇 자리까지 쓸지, 반올림인지 버림인지가 채점 결과를 바꿀 수 있습니다 → Q-02.
  - 임시 기준은 소수 둘째 자리 반올림입니다.

## D-008 그래프
- **상태**: 잠정 (Q-04)
- **결정**: 요구사항 #2의 4종을 만듭니다.
  1. 주요 손익 전기·당기 비교 (매출, 영업이익, 당기순이익)
  2. 판관비 구성비 (%) 원그래프. 상위 6개 + 기타로 묶습니다.

  - Q-04에서 통일할지 묻습니다.

## D-009 증감률
- **상태**: 잠정 (Q-03)
- **결정**
  - 증감액 = 당기 − 전기
  - 증감률 = (당기 − 전기) ÷ |전기| × 100
  - 부호가 바뀌는 경우: 영업손익 -15,385,718 → 49,254,390, 당기순손익 -15,510,353 → 46,496,124. 숫자 대신 **«흑자전환»**으로 표기합니다. 반대 경우는 «적자전환», 둘 다 음수면 «적자지속»입니다.
  - 전기가 0이면 «신규»로 표기합니다 (예: 법인세비용 0 → 2,719,623, 보험료 0 → 2,021,410).
  - 비율 항목(부채비율)의 증감은 %p로 씁니다.
- **이유**: 공식대로 계산하면 영업이익 +420.13%가 나옵니다. 숫자로는 맞지만 업무상 오해를 부르므로 기준 확인이 필요합니다.

## D-010 영업외손익
- **상태**: 설계
- **결정**: 요약 손익의 「영업외손익」 = 영업외수익 − 영업외비용
  - 2024: 4,975 − 129,610 = **-124,635**
  - 2025: 6,837 − 45,480 = **-38,643**
- **근거**: 요구사항 #4 항목 목록에 「영업외손익」이 한 줄로 들어 있습니다. 결산서에는 수익·비용 줄만 있습니다.
- **메모**: 요약 코멘트(요구사항 #3-3)에는 내역을 적습니다. 이자수익과 잡이익만 있고, 단기투자자산처분익·외환차익은 없습니다.

## D-016 문서 파싱 도구: kordoc 적용
- **상태**: 설계 · 2026-11-21
- **결정**
  - 한국 문서 파서 **kordoc**(github.com/chrisryugj/kordoc, MIT)을 프로젝트에 넣습니다.
    - 스킬 위치: `.claude/skills/kordoc/SKILL.md`
    - 실행: `npx -y kordoc@4.25.2 …`
  - 4개 입력 파일 전체를 Markdown으로 바꿔 `input/_parsed/`에 저장했습니다.
  - 역할은 이렇게 나눕니다.

  | 용도 | 도구 | 이유 |
  |---|---|---|
  | Excel 2종 읽기 | **kordoc** | 셀 병합·줄바꿈을 포함해 요구사항 표를 그대로 Markdown으로 만들어 줌 |
  | PDF 전체 구조 파악, 서식 검색, 근거 인용 | **kordoc** (`--format json`, `-p` 범위) | 서식 제목이 `#` 헤딩으로 나와 서식 → 페이지 찾기가 쉬움 |
  | 재무제표 **숫자 추출** | **레이아웃 텍스트**(`pdftotext -layout` / pdfplumber) 줄 단위 파서 | kordoc은 결산 재무상태표·손익계산서의 계정명과 금액을 셀 한 칸에 `<br>`로 몰아 넣음 (2025 p54~55에서 확인). 그러면 줄 단위 매칭이 어긋남 |
  | 교차 검증 | 두 결과 비교 | 같은 값이 양쪽에서 나와야 «확정» |

- **확인한 사실**
  - 원본 SKILL.md가 고정한 `kordoc@4.25.3`은 npm에 아직 없습니다 (ETARGET). 최신 `4.25.2`로 바꿔 둡니다.
  - Node 20 이상이 필요합니다. 리눅스에서 sharp 설치가 실패하면 `ONNXRUNTIME_NODE_INSTALL=skip`을 붙입니다.
  - 1차 PDF는 텍스트 PDF라 OCR이 필요 없습니다. 2~4차에 스캔본이 오면 `kordoc --ocr`을 1순위 경로로 씁니다.
- **대안**
  - pdfplumber만 쓰기 → 스캔본과 HWP 대응이 안 됩니다.
  - kordoc만 쓰기 → 재무제표 표 구조가 무너집니다.
