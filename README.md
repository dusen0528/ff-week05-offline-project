# ff-week05-offline-project — 법인세 분석 보고서 자동화

같은 회사의 **세무조정계산서 PDF 두 개(전기·당기)**를 넣으면
**법인세 분석 보고서 PDF**와 **조정료청구서**를 만드는 프로그램입니다.
1차부터 4차까지, 차수마다 새 자료를 받아 **같은 프로그램을 계속 고쳐 나갑니다**.

## 핵심 원칙
1. 보고서의 숫자마다 **출처(파일 · 서식 · 페이지)**를 추적할 수 있어야 합니다.
2. 기준이 모호하면 **추측하지 않고 고객 담당자에게 질문**합니다. 확정 전까지는 «확인 필요»로 표시합니다.
3. «확인 필요»는 채점에서 **오답**입니다. 자료와 답을 받아 확정한 뒤 다시 실행합니다.
4. 기준값은 하드코딩하지 않고 `config/`에 둡니다. 답을 받으면 설정만 바꿔 다시 실행합니다.

## 폴더 구조
```
ff-week05-offline-project/
├── README.md
├── docs/
│   ├── SPEC.md          # 요구사항 명세 (기능·비기능·데이터·채점 기준)
│   ├── FORM_MAP.md      # 서식 · 페이지 맵 (어느 값이 어느 PDF 어디에 있는지)
│   ├── QUESTIONS.md     # 고객 질문 로그 (원본 질문 보존 + 답변 분류)
│   └── ROUNDS.md        # 차수별 진행 · 제출 · 피드백 기록
├── input/round1/        # 1차 자료 (요구사항 Excel, 출력 예시 Excel, 샘플컴퍼니 2024·2025 PDF)
├── config/              # 항목 매핑 · 계산 기준 · 단위 등 설정
├── src/                 # 프로그램 코드
├── output/              # 생성된 보고서 · 청구서 · 근거 표
└── logs/                # 실행 로그 · 검산 결과
```
